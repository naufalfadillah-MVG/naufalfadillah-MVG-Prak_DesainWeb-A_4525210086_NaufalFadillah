# Tugas 6 — Profil Restoran Dapur Rempah Nusantara

## Deskripsi

Studi kasus ini berisi halaman profil restoran Dapur Rempah Nusantara yang dibuat menggunakan HTML dan CSS eksternal. Halaman menampilkan navigasi, informasi utama restoran, menu favorit, formulir kontak, dan footer dengan informasi restoran.

## Struktur File

- `Tugas/index.html` — struktur HTML halaman profil restoran.
- `Tugas/CSS/style.css` — pengaturan tampilan menggunakan CSS eksternal.
- `Tugas/dokumentasi/hasil1 dekstop.png` — bukti tampilan desktop bagian pertama.
- `Tugas/dokumentasi/hasil2 dekstop.png` — bukti tampilan desktop bagian kedua.
- `Tugas/dokumentasi/hasil3 dekstop.png` — bukti tampilan desktop bagian ketiga.
- `Tugas/dokumentasi/hasil4 dekstop.png` — bukti tampilan desktop bagian keempat.
- `Tugas/dokumentasi/hasil1 mobile.png` — bukti tampilan mobile bagian pertama.
- `Tugas/dokumentasi/hasil2 mobile.png` — bukti tampilan mobile bagian kedua.
- `Tugas/dokumentasi/hasil3 mobile.png` — bukti tampilan mobile bagian ketiga.
- `Tugas/dokumentasi/hasil4 mobile.png` — bukti tampilan mobile bagian keempat.

## Pemeriksaan Kebutuhan

Halaman memiliki navbar dengan tautan Beranda, Menu, dan Kontak. Bagian beranda berisi pengenalan restoran dan tombol navigasi. Bagian menu menampilkan tiga pilihan makanan beserta deskripsi, harga, dan status. Bagian kontak berisi formulir nama, email, dan pesan. Footer menampilkan alamat, nomor telepon, email, serta informasi hak cipta. CSS dihubungkan melalui elemen `<link rel="stylesheet" href="css/style.css">`.

CSS menggunakan Flexbox dan Grid untuk mengatur tata letak. Media query pada lebar layar maksimal 768px menyesuaikan susunan elemen agar lebih nyaman dilihat pada perangkat mobile.

## Ringkasan Perubahan, Masalah, dan Solusi

Halaman dibuat dengan tema restoran bernama Dapur Rempah Nusantara, menggunakan warna bernuansa hijau dan latar terang. Menu disajikan dalam bentuk kartu agar informasi mudah dibaca. Pada layar kecil, tata letak hero, kartu menu, navigasi, dan footer disesuaikan menggunakan media query supaya konten tetap tertata.
