# Studi Kasus — Wireframe Company Profile

## Deskripsi

Studi kasus ini berisi wireframe halaman company profile untuk PT Industri 2100. Halaman dibuat menggunakan HTML dan CSS eksternal dengan tampilan wireframe yang menampilkan bagian navigasi, beranda, tentang perusahaan, layanan, kontak, dan footer.

## Struktur File

- `tugas/index.html` — struktur HTML halaman company profile.
- `tugas/css/style.css` — pengaturan tampilan menggunakan CSS eksternal.
- `tugas/images/hasil desktop.png` — bukti tampilan pada desktop.
- `tugas/images/hasil mobile1.png` — bukti tampilan mobile.
- `tugas/images/hasil mobile2.png` — bukti tampilan mobile.
- `tugas/images/hasil mobile3.png` — bukti tampilan mobile.
- `tugas/images/hasil mobile4.png` — bukti tampilan mobile.

## Pemeriksaan Kebutuhan

Halaman memiliki navbar dengan tautan ke bagian Beranda, Tentang, Layanan, dan Kontak. Konten dibagi menjadi hero section, informasi perusahaan dan statistik, daftar layanan, serta informasi kontak dan footer. File CSS dihubungkan menggunakan elemen `<link rel="stylesheet" href="css/style.css">`.

CSS menggunakan Flexbox untuk mengatur tata letak bagian halaman. Media query pada lebar layar maksimal 768px mengubah beberapa bagian menjadi susunan kolom agar lebih sesuai untuk perangkat mobile.

## Ringkasan Perubahan, Masalah, dan Solusi

Wireframe menggunakan kotak dengan garis putus-putus dan label anotasi untuk menandai bagian-bagian halaman. Area gambar masih berupa placeholder, sehingga dapat diganti dengan gambar asli pada tahap desain berikutnya. Untuk layar kecil, navbar dan bagian konten diatur ulang menjadi susunan vertikal melalui media query.
