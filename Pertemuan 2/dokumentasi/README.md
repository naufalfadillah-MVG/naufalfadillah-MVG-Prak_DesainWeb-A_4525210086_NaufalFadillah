## Ringkasan

Halaman web ini dibuat untuk menampilkan profil organisasi mahasiswa Teknik Informatika, yaitu Ikatan Mahasiswa Teknik Informatika (IMATIKA) Universitas Pancasila. Halaman dibuat menggunakan HTML untuk memenuhi kebutuhan praktikum desain web.

Website memiliki beberapa bagian utama, yaitu identitas organisasi, divisi dan program kerja, alur open recruitment, istilah penting, serta kontak organisasi. Navigasi internal digunakan untuk memudahkan pengguna berpindah dari satu bagian ke bagian lainnya menggunakan atribut `id` dan tautan dengan tanda `#`.

Dalam pembuatan halaman ini digunakan tiga jenis list HTML. Tag `<dl>` digunakan untuk menampilkan informasi identitas organisasi, `<ul>` digunakan untuk menampilkan daftar divisi atau program kerja, sedangkan `<ol>` digunakan untuk menjelaskan tahapan open recruitment secara berurutan.

Halaman juga dilengkapi dengan dua gambar yang relevan dengan organisasi, yaitu logo IMATIKA dan foto kegiatan organisasi. Setiap gambar diberikan atribut `alt` sebagai keterangan alternatif. Selain itu, terdapat tautan eksternal menuju situs Universitas Pancasila serta tautan email menggunakan `mailto`.

## Fitur HTML yang Digunakan

* Image (`<img>`) dengan atribut `alt`
* Unordered List (`<ul>`)
* Ordered List (`<ol>`)
* Description List (`<dl>`)
* Internal Link menggunakan anchor
* External Link
* Email Link menggunakan `mailto`
